## 1. 준비 — GitHub 가입 + 권한 받기 (최초 1회만)

### 1-1. GitHub 가입
1. https://github.com/signup 접속
2. 이메일 → 비밀번호 → 아이디(영문) 입력, 이메일 인증까지 완료
3. 요금제는 **Free** 선택 (무료로 충분합니다)

### 1-2. 수정 권한 받기
가입만 해서는 남의 저장소를 고칠 수 없습니다. **이전 관리자에게 본인 GitHub 아이디를 알려주고 권한을 받으세요.**

> 이전 관리자가 할 일:
> 저장소 → **Settings → Collaborators → Add people** → 새 관리자 아이디 입력 → 권한 **Write**

초대 메일이 오면 **Accept invitation**을 눌러야 권한이 살아납니다.

✅ 확인법: https://github.com/HSB9912/guild-manager 에 들어가서 파일을 열었을 때 **연필(✏️) 아이콘**이 보이면 성공입니다. 안 보이면 권한이 아직 없는 것.

## 2. 파일 찾아가기

두 가지 방법 중 편한 걸로:

- **빠른 길**: [이 링크](https://github.com/HSB9912/guild-manager/edit/main/join/index.html)를 누르면 바로 편집 화면
- **직접 찾아가기**: https://github.com/HSB9912/guild-manager → `join` 폴더 클릭 → `index.html` 클릭 → 오른쪽 위 **연필(✏️) 아이콘** 클릭

편집 화면이 열리면 코드가 쭉 보입니다. **겁먹지 말고, 고칠 글자만 찾아서 고치면 됩니다.**

---

## 3. 🔥 신규 직업 추가하기 (가장 자주 하는 작업)

### 3-1. 직업 목록 찾기
편집 화면에서 **`Ctrl + F`** (맥은 `Cmd + F`) 를 누르고 **`const JOBS`** 를 검색하세요.
**293번째 줄쯤**에 이런 줄이 나옵니다.

```javascript
const JOBS = ['히어로','팔라딘','다크나이트','아크메이지(불,독)', ... ,'키네시스','렌'];
```

이게 가입 폼의 **직업 선택 목록**입니다. 지금 47개가 들어 있습니다.

### 3-2. 새 직업 추가
맨 끝 `'렌'` 뒤에 **쉼표(,)** 를 찍고 `'새직업이름'` 을 넣으면 끝입니다.

**고치기 전**
```javascript
...,'제로','키네시스','렌'];
```

**고친 후** (예: `아처` 라는 직업이 새로 나왔다면)
```javascript
...,'제로','키네시스','렌','아처'];
```

### ⚠️ 꼭 지킬 것 3가지

| 규칙 | 잘못된 예 | 올바른 예 |
|------|-----------|-----------|
| **작은따옴표** `'`로 감싸기 | `,아처]` | `,'아처']` |
| 직업 사이에 **쉼표** | `'렌' '아처'` | `'렌','아처'` |
| 맨 끝 **`];`** 는 그대로 두기 | `,'아처'` | `,'아처'];` |

> 💡 **직업 이름은 게임에 표시되는 그대로** 써주세요.
> 동기화 기능이 넥슨에서 가져오는 이름과 글자가 다르면 나중에 통계에서 따로 잡힙니다.
> (괄호가 들어가는 직업은 `'아크메이지(불,독)'` 처럼 **괄호까지 똑같이**)

## 4. 그 밖에 자주 고치는 것

`Ctrl + F` 로 아래 단어를 검색하면 바로 찾을 수 있습니다.

| 고치고 싶은 것 | 검색할 단어 | 설명 |
|---------------|------------|------|
| 수로 이벤트 안내 문구 | `수로 상시 이벤트 안내` | 크라운/파르페/티라미슈 등급 설명 |
| 가입 컷 기준 | `가입 컷` | "꼴등 +5,000점" 같은 기준 |
| 보상 분배 비율 | `크라운 TOP 5` | 1등 28% · 2등 24% … 부분 |
| 페이지 제목 | `버니 가입 신청` | 맨 위 큰 제목 |

**글자만 고치세요.** `<div>` `<strong>` 같은 꺾쇠 괄호 태그는 건드리지 않는 게 안전합니다.

```html
<!-- 이렇게 글자만 -->
<div>• 👑 <strong>크라운 TOP 5</strong> = 보상 풀 <strong>100억 차등 분배</strong></div>
                    ↑ 여기 숫자·글자만 고치기        ↑ 여기도 OK
```

## 5. 저장하기 (= 커밋 = 배포)

수정이 끝났으면:

1. 화면 **오른쪽 위 초록색 `Commit changes...` 버튼** 클릭
2. 창이 하나 뜹니다:
   - **첫 칸(제목)**: 뭘 바꿨는지 짧게. 예) `가입폼 신규 직업 아처 추가`
   - 아래 칸(설명)은 비워도 됩니다
   - **`Commit directly to the main branch`** 가 선택돼 있는지 확인 ← 중요
3. 초록색 **`Commit changes`** 버튼 클릭

이게 끝입니다. **커밋 = 저장 = 자동 배포**입니다. 따로 업로드할 것 없습니다.

> (다른 페이지 `assets/app.js`를 고칠 때는 규칙이 다릅니다 → [WORKLOG.md](../WORKLOG.md) 참고)

## 7. 😱 실수했을 때 — 되돌리기

**사이트가 깨졌거나 잘못 저장했어도 100% 복구됩니다.** 모든 변경 기록이 남아 있습니다.

1. https://github.com/HSB9912/guild-manager/commits/main/join/index.html 접속
2. 목록에서 **잘못 저장하기 직전 항목**을 찾습니다
3. 오른쪽 **`< >` (View at this point)** 아이콘 클릭 → 그때의 파일이 열립니다
4. 연필(✏️) → 내용 전체 선택(`Ctrl+A`) → 복사(`Ctrl+C`)
5. [현재 파일 편집화면](https://github.com/HSB9912/guild-manager/edit/main/join/index.html)에서 전체 선택 후 **붙여넣기** → Commit

> 더 쉬운 방법: 잘못된 커밋 화면에서 **`Revert`** 버튼이 보이면 그것만 눌러도 됩니다.

## 8. ⛔ 주의사항

- **파일 이름을 바꾸지 마세요.** `index.html` 이 아니면 페이지가 열리지 않습니다.
- **`join` 폴더를 옮기거나 지우지 마세요.** 주소가 `/join/` 이라 폴더 이름이 곧 주소입니다.
- 큰 수정을 할 거면 **작은 것부터 하나씩** 고치고 확인하세요. 한 번에 많이 고치면 어디서 틀렸는지 찾기 어렵습니다.
- 신청 내용이 저장되는 곳(데이터베이스)은 이 파일이 아닙니다. **폼에 새 질문 항목을 추가하는 건 저장 코드도 같이 고쳐야 해서**, 그건 개발을 아는 사람에게 맡기세요.
- 잘 모르겠으면 **고치지 말고 물어보세요.** 되돌리는 것보다 안 건드리는 게 빠릅니다.
