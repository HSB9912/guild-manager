방향 1
그냥 둔다 — 5.9% 손실 무시
월 60조각 손실 ≈ 운영진 1명당 30조각 → 무의미한 규모. 아무것도 안 하는 게 베스트 선택지일 수 있음.
방향 2
길드 그룹 5캐릭에 수로 의무 부과
본캐 1 + 부캐 5명도 혜택 받으니까 수로 의무도 분담 (예: 본캐 100%, 부캐 50% 의무). 미참 시 부캐도 보석금 청구 → 자연 수입 ↑, 운영진 노동은 자동화로 처리.
⚠ 룰 합의 필요 — 부캐 의무율이 핵심
방향 3
누진세 영구 누적 (반기 초기화 제거)
현재 누진은 반기마다 리셋되어 약함 (x2 11건만, 전체의 12.5%). 영구 누적 시 상습 미참자 부담 ↑, 성실 멤버 영향 0. 단가 인상 없이도 같은 사람한테 알아서 누진.
💡 누진 정책 강화는 사이트 코드 1줄 수정으로 가능
방향 4
운영진 노동 자동화 (수입은 그대로, 부담만 ↓)
진짜 문제는 "수입"이 아니라 "운영진 노동 시간".
  • 입금 스샷 자동 검증 (이미지에서 메모/금액 OCR)
  • 노블 해제 알림 → 인게임 매크로 안내
  • 솔에르다 자동 환금 트래커 (시세 자동 계산)
  • 이벤트 보상 자동 분배 풀
  • 주간 미참 자동 감지·자동 청구 메시지
→ 운영진 손 안 가게 만드는 게 핵심.
🏆

최종 추천 — 방향 1 + 4

"단가 그대로, 부길드 손실 무시, 운영진 노동만 자동화로 줄이기"
  • ✓ 보석금 단가 그대로 (뚠 80, 뚱 40)
  • ✓ 부길드 사라져도 월 -60 조각만 손실 → 무시 가능
  • ✓ 누진세는 그대로 유지 (현재 반기 초기화 방식 OK)
  • ✓ 운영진 노동 자동화 항목 → 사이트가 다 해주게
  • ✓ 멤버에게 "추가 부담 없음" 메시지 → 반발 0
근거: 실데이터 보니 부길드 비중 5.9%로 작음. 인상하면 멤버 반발 + 형평성 시비 비용이 더 클 것. 진짜 부담은 운영 노동이므로 그쪽을 자동화 — 운영진 손은 줄고 수입은 유지.
