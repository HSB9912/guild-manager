길드 2개 체제 — 운영 리빌딩 옵션 5가지

밤·별·달·꿀·솜카롱 해체 → 뚠카롱·뚱카롱 2개만 남는 시나리오 대비

🎯 풀어야 할 문제
📉 보석금 수입 ↓
길드 수↓ → 멤버 수 자연 감소 → 수로 미참 보석금 풀 ↓
📈 운영진 부담 →
이벤트·관리 비용은 그대로 (혹은 ↑) → 운영진 사비 부담 위험
😊 멤버 부담 ↓
부캐 일일이 수로 안 돌려도 됨 → 자동 혜택 → 좋은 신호
💎
옵션 1

길드 가입금 도입

신규 가입 시 1회성 메소(예: 5억~10억) 납부 → 안정적 기초 수입

✅ 장점
  • 수입이 명확·예측 가능
  • 가입자 진성도 검증 (장벽)
  • 잘못 받아도 환불 정책 명확하게 가능
❌ 단점
  • 신규 모집 진입장벽 ↑
  • "길드인데 돈 받냐" 반발 가능
  • 기존 멤버 형평성 이슈 (전환 비용)
멤버 부담
1회성 5~10억
📊
옵션 2

활동 점수제 + 차등 보석금

월 활동 점수 ≥ X → 보석금 면제/할인   vs   활동 ↓ → 누진 보석금

✅ 장점
  • 활동 적극 멤버는 부담 ↓ (보상감)
  • 비활동 멤버는 자동 정리 효과
  • "공정함" 명분 → 반발 적음
❌ 단점
  • 점수 산정 룰 합의 필요
  • 운영진 정산 작업 ↑ (자동화 필수)
  • 점수 게이밍 리스크
멤버 부담
활동량에 비례
🤝
옵션 3

이벤트 호스트(스폰서) 모집제

운영진은 기획·진행만, 보상 메소는 멤버 스폰서가 분담 → 호스트는 명예/배지

✅ 장점
  • 운영진 사비 부담 ↓↓
  • 참여형 운영 → 공동체 강화
  • 여유 있는 멤버가 자발적 기여
❌ 단점
  • 호스트 안 모이면 이벤트 무산
  • "운영진 일 떠넘김" 인식 위험
  • 호스트 명예 시스템 별도 설계 필요
멤버 부담
자발적 참여만
🏦
옵션 4

운영 펀드 + 투명 회계 공개

길드 금고를 "운영비/이벤트비/예비비"로 분리 → 사이트에서 잔액·지출 실시간 공개

✅ 장점
  • 운영진 투명성 → 신뢰 ↑
  • 부족분 명시 → 자발 후원 유도
  • 회계 의심·소문 차단
❌ 단점
  • 회계 기록·공개 작업 필요 (자동화로 해결)
  • 그 자체로 수입 증가 효과 ↓
  • 다른 옵션과 조합 필요
멤버 부담
없음 (인프라성)
🎫
옵션 5

월정액 멤버십 (선택제)

A형: 월 3~5억 정액 → 보석금 면제   vs   B형: 활동제(기존 유지) → 멤버 선택

✅ 장점
  • 안정적 정기 수입 확보
  • 멤버 선택권 → 강제성 ↓
  • 여유 멤버는 편의성 구매 → 윈윈
❌ 단점
  • 2가지 트랙 관리 복잡도 ↑
  • "돈으로 면제 사기" 비판 가능
  • 가격 책정 합의 어려움
멤버 부담
선택형 — 본인 결정
🏆

추천 조합 — 2+3+4 하이브리드

"강제 부담은 줄이고, 자발적 참여는 늘리고, 운영진은 투명성으로 신뢰 확보"
기초
옵션 2 (활동 점수제) — 멤버 부담은 활동량에 비례, 비활동 자동 정리 효과
이벤트
옵션 3 (호스트 모집제) — 큰 이벤트는 스폰서 모집, 운영진은 기획·진행
신뢰
옵션 4 (투명 회계) — 사이트에 금고 현황 공개 + 후원자 명예 표시
💡 왜 이 조합? 옵션 1·5(돈 요구)는 정서적 저항 큼. 2+3+4는 "공정성·자발성·투명성" 3대 명분으로 묶여서 멤버 반발 ↓, 운영진 부담 ↓, 신뢰 ↑. 사이트 자동화로 운영 노동도 줄여줌.
🔧 어떤 옵션을 골라도 사이트가 해줘야 할 것
📊 활동 점수 자동 산정 (수로·토벌·접속)
💰 금고 입출금 자동 기록 + 카테고리 분류
🎯 호스트·후원자 자동 명예 배지/랭킹
📈 멤버별 누적 기여도 대시보드
🔔 부족 자금 자동 알림 (디스코드)
📋 이벤트 스폰서 모집/마감 자동 처리
