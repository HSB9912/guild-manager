🔗 길드원 계정 그룹 묶기 — 미리보기

계정 그룹끼리 묶어서 대표캐릭의 수로 여부를 파악하는 화면 3안. 클릭해서 비교해봐.

🗂️
A · 그룹 카드
그룹마다 카드 한 장. 대표 + 수로 상태 큰 배지, 부캐는 펼쳐보기. KPI(완료 N/M)·미참 필터.
한눈에 · 카드형
🌳
B · 트리 테이블
대표/부캐 들여쓰기 표. 대표 행에 수로 여부. 묶기 편집 모드로 부캐를 다른 대표에 옮기거나 대표 승격.
묶기 관리 · 표형
📋
C · 수로 점호
이번 주 점호판. 완료율 바 + ✅/❌ 타일(미참 먼저), 타일 클릭하면 옆에 부캐·점수. 미참 알림까지.
점호 · 작업형
💡 데이터 출처 — 묶기 기준은 members.main_char_name(본/부캐 링크) + 넥슨 계정그룹 동기화. 대표 수로 여부는 최신 회차 suro_scores(대표=본캐 점수>0)로 판정.
섞어 쓰기도 가능 — 예: 길드원 페이지엔 A(카드)를 기본, 수로 입력 전 점검용으로 C(점호)를 별도 탭, 운영진 묶기 관리에 B(편집). 맘에 드는 거 / 섞을 조합 알려줘.
